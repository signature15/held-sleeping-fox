## Purpose

A tiny Node 22 program that writes one quiet, fixed still-life sentence to `entry.txt`. The fox, the snow, and the small warmth of her breathing offer a contained image for a relaxation judge.

## Run

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose another destination; otherwise the file is written to `./output/entry.txt`.
